# proyecto01

Proyecto Django local. Repositorio inicializado por asistente.

Instrucciones rápidas para subir al remoto (GitHub):

1. Crear repo en GitHub (web o `gh repo create`).
2. Añadir remote y hacer push:

```
git remote add origin https://github.com/<tu_usuario>/<tu_repo>.git
git push -u origin main
```
